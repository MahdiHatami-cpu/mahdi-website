# OpenFront site files

The static files (`assets/`, `_assets/`) of an OpenFront deployment, published here so that
jsDelivr can serve them: `https://cdn.jsdelivr.net/gh/<user>/<repo>@<commit>/assets/...`.
Every file name carries a content hash; nothing here is edited by hand. Generated by
`cloudflare/scripts/cdn-repo.ts` in the game's repository.
